## 2. Phase 1 — False Sharing & Karp-Flatt

M = 24,000,000 total RMW steps, p = P_phys = 8.

**Table 1A — stride sensitivity**

| stride (words) | separation (B) | median (ms) | IQR (ms) | throughput (Mops/s) |
|---|---|---|---|---|
| 1 | 8 | 760.29 | 33.92 | 31.57 |
| 2 | 16 | 776.25 | 70.16 | 30.92 |
| 4 | 32 | 769.40 | 33.24 | 31.19 |
| 8 | 64 | 797.60 | 32.58 | 30.09 |
| 16 | 128 | 777.21 | 25.54 | 30.88 |
| 32 | 256 | 816.19 | 22.00 | 29.40 |

The largest step between neighbouring strides is 2.6% (at 128 B, which equals the reported 128-byte line), but all six medians lie within 7.4% of each other, inside the run-to-run noise (max IQR/median = 9.0%). **On this CPU the false-sharing penalty is not resolvable from pure Python.** Each loop iteration costs about 253 ns of wall time per worker (bigint multiply, masking, ctypes store and bytecode dispatch, plus process spawn), while a cache-line transfer between cores costs on the order of tens of nanoseconds. Apple's cores also absorb repeated stores to the same line in the store buffer, so the coherence traffic is a small fraction of the iteration time and is hidden by interpreter overhead. The expected boundary for this CPU is 128 B (stride = 16).

**Table 1B — Karp-Flatt diagnostic series**

| p | T (s=1) ms | S (s=1) | E (s=1) | e(p) (s=1) | T (s=16) ms | S (s=16) | E (s=16) | e(p) (s=16) |
|---|---|---|---|---|---|---|---|---|
| 1 | 3164.9 | 1.000 | 1.000 | — | 3159.5 | 1.000 | 1.000 | — |
| 2 | 1691.4 | 1.871 | 0.936 | 0.0688 | 1755.5 | 1.800 | 0.900 | 0.1112 |
| 4 | 1018.5 | 3.107 | 0.777 | 0.0957 | 1019.1 | 3.100 | 0.775 | 0.0967 |
| 8 | 852.1 | 3.714 | 0.464 | 0.1648 | 809.6 | 3.903 | 0.488 | 0.1500 |

**Forensic explanation.** With stride = 1, e(p) goes from 0.0688 to 0.1648 as p grows; with stride = 16 it goes from 0.1112 to 0.1500 (difference at p = 8: +0.0148). The worker code has no serial section, so any e(p) above zero is overhead that behaves like serial work. In theory, under stride = 1 all slots share one or two cache lines: every store needs the line in the Modified state, so the coherence protocol invalidates the other cores' copies and the next writer must fetch it back. Those transfers are serialised on the line and grow with the number of writers, so e(p) should rise faster than with stride = 16, where each slot owns its line. 
In the measured data the two series are almost the same, so false sharing is not the main driver here. The rise of e(p) with p in **both** series comes from (1) process spawn/join cost, which does not shrink with p, and (2) core heterogeneity: at p = 8 half of the workers run on the slower efficiency cores, so the run waits for the slowest worker. The coherence effect is too small to stand out against interpreter overhead, consistent with Table 1A.

## 5. Phase 4 — Scheduling & Load Imbalance

N = 12,000 items, K(i) = 1 + ⌊(i/60)²⌋, p = 8.

| Strategy | T_wall (ms) | IQR (ms) | max t_worker (ms) | mean t_worker (ms) | λ |
|---|---|---|---|---|---|
| Static block | 6098.2 | 257.4 | 5996.0 | 2492.6 | 2.406 |
| Static cyclic | 3631.7 | 126.9 | 3526.8 | 3481.1 | 1.013 |
| Dynamic C=1 | 3738.6 | 52.0 | 3625.9 | 3619.4 | 1.002 |
| Dynamic C=4 | 3738.9 | 27.3 | 3634.9 | 3618.5 | 1.005 |
| Dynamic C=16 | 3838.0 | 37.7 | 3722.9 | 3686.5 | 1.010 |
| Dynamic C=64 | 3897.5 | 51.3 | 3795.7 | 3657.6 | 1.038 |
| Dynamic C=256 | 4063.7 | 61.3 | 3961.2 | 3484.6 | 1.137 |
| Dynamic C=1024 | 4917.5 | 231.9 | 4819.5 | 3062.3 | 1.574 |

**Trade-off.** Static block gives λ = 2.41: the last worker owns the heaviest part of the triangle while the others idle at the join. Cyclic interleaving spreads heavy and light items evenly (λ = 1.01). In the dynamic queue, C = 1 balances almost perfectly (λ = 1.002) but every item costs a lock acquire on the shared counter, whose cache line bounces between cores (T_wall = 3738.6 ms). C = 1024 claims only ~12 chunks in total, so synchronisation is negligible, but the last chunks are huge and the tail is unbalanced (λ = 1.574, T_wall = 4917.5 ms). The best chunk on this CPU is **C* = 1** (T_wall = 3738.6 ms, λ = 1.002), 1.63× faster than static block.

C = 1 and C = 4 differ by only 0.2 ms, inside the measurement noise, so any chunk in that range is effectively optimal: each item here costs milliseconds of work, so even one lock per item is cheap compared with the work it protects. 
Cyclic static scheduling was slightly faster than the best dynamic run (3631.7 vs 3738.6 ms): the skew K(i) changes smoothly, so round-robin already balances the work (λ = 1.013) with zero synchronisation. Dynamic scheduling would win for irregular skew that cyclic distribution cannot predict, and on a hybrid CPU it also lets fast cores take more items than slow ones.

```python
from dataclasses import dataclass
import multiprocessing as mp
import time
from typing import Callable


@dataclass
class BenchStats:
    min_ms: float
    median_ms: float
    iqr_ms: float
    max_ms: float


def fnv1a_hash(s: str) -> int:
    h = 14695981039346656037
    for b in s.encode("utf-8"):
        h ^= b
        h = (h * 1099511628211) & 0xFFFFFFFFFFFFFFFF
    return h


def run_benchmark(fn: Callable[[], None], warmup_runs: int = 3, timed_runs: int = 9) -> BenchStats:
    for _ in range(warmup_runs):
        fn()
    samples = []
    for _ in range(timed_runs):
        t0 = time.perf_counter_ns()
        fn()
        t1 = time.perf_counter_ns()
        samples.append((t1 - t0) / 1e6)
    samples.sort()
    mid = timed_runs // 2
    med = samples[mid] if timed_runs % 2 == 1 else 0.5 * (samples[mid - 1] + samples[mid])
    q25 = samples[timed_runs // 4]
    q75 = samples[(3 * timed_runs) // 4]
    return BenchStats(samples[0], med, q75 - q25, samples[-1])


def emit_verify_tag(task_id: str, student_seed: int,
                    primary_metric: float, secondary_metric: float) -> str:
    hw = mp.cpu_count()
    payload = (
        f"{task_id}|{student_seed}|{hw}|"
        f"{primary_metric:.4f}|{secondary_metric:.4f}"
    )
    sig = fnv1a_hash(payload)
    return f"VERIFY_HASH[{task_id}]: {sig:016X} (P_log={hw})"

```

```python
    resource tracker (avoids bogus 'leaked shared_memory' warnings on macOS)."""

    except TypeError:
        shm = shared_memory.SharedMemory(name=name)
        try:
            from multiprocessing import resource_tracker
            resource_tracker.unregister(shm._name, "shared_memory")
        except Exception:
            pass
        return shm

    return "\n".join(out)
```

```python
"""Phase 1 - false sharing / cache-line contention + Karp-Flatt."""
import ctypes
import multiprocessing as mp
from multiprocessing import shared_memory

from harness import run_benchmark, emit_verify_tag
from lab_common import STUDENT_ID, save_results, scale, p_phys, p_log, attach_shm, log

M_TOTAL = scale(24_000_000, 600_000)
STRIDES = [1, 2, 4, 8, 16, 32]
WARMUP, TIMED = scale(2, 1), scale(7, 3)


def fs_worker(shm_name: str, slot_idx: int, iters: int) -> None:
    shm = attach_shm(shm_name)
    arr = (ctypes.c_uint64 * 512).from_buffer(shm.buf)
    acc = arr[slot_idx]
    mask = 0xFFFFFFFFFFFFFFFF
    mult = 6364136223846793005
    for i in range(iters):
        acc = (acc * mult + (i | 1)) & mask
        arr[slot_idx] = acc            # store to the shared cache line every iteration
    del arr                            # release buffer export before closing
    shm.close()


def make_run(shm_name, p, stride):
    iters = M_TOTAL // p

    def run():
        procs = [mp.Process(target=fs_worker, args=(shm_name, t * stride, iters)) for t in range(p)]
        for pr in procs:
            pr.start()
        for pr in procs:
            pr.join()
    return run


def p_list(plog):
    ps, p = [], 1
    while p < plog:
        ps.append(p)
        p *= 2
    ps.append(plog)
    return ps


def main():
    out = []
    P, PL = p_phys(), p_log()
    shm = shared_memory.SharedMemory(create=True, size=4096)
    try:
        # ---------- Table 1A: stride sweep at p = P_phys ----------
        log(out, f"=== Phase 1A: stride sweep, p = P_phys = {P}, M = {M_TOTAL} ===")
        t1a = []

                     f"IQR={st.iqr_ms:8.2f} ms  {mops:7.2f} Mops/s")

        # biggest relative drop between consecutive strides = coherence boundary
        drops = [(t1a[i - 1]["median_ms"] - t1a[i]["median_ms"]) / t1a[i - 1]["median_ms"]
                 for i in range(1, len(t1a))]
        k = max(range(len(drops)), key=lambda i: drops[i]) + 1
        boundary = t1a[k]["bytes"]
        log(out, f"Largest time drop: {t1a[k-1]['bytes']} B -> {boundary} B "

        # ---------- Table 1B: process scaling with stride 1 and 16 ----------
        t1b = {}
        for s in (1, 16):
            log(out, f"=== Phase 1B: scaling sweep, stride = {s} ===")
            rows, T1 = [], None
            for p in p_list(PL):
```

```python
"""Phase 2 - strong (Amdahl) vs weak (Gustafson) scaling."""
import math
import multiprocessing as mp
import statistics
import time

from harness import run_benchmark, emit_verify_tag
from lab_common import STUDENT_ID, save_results, scale, hw, p_phys, p_log, log

N_STRONG = scale(1_600_000, 80_000)
N0_WEAK = scale(250_000, 12_500)
WARMUP, TIMED = scale(1, 0), scale(5, 3)
SERIAL_FRAC = 0.05


def stage_a(n_serial: int) -> float:
    """Strictly serial prefix reduction: 12 transcendental ops per element."""
    acc, kept = 0.0, 0
    sin, sqrt = math.sin, math.sqrt
    for i in range(n_serial):
        v = 1.0 + i * 1e-5
        v = sin(v); v = sqrt(v * v + 1.0); v = sin(v); v = sqrt(v * v + 1.0)
        v = sin(v); v = sqrt(v * v + 1.0); v = sin(v); v = sqrt(v * v + 1.0)
        v = sin(v); v = sqrt(v * v + 1.0); v = sin(v); v = sqrt(v * v + 1.0)
        acc += v
        if acc > 0.0:
            kept += 1
    return acc + kept


def stage_b(rng) -> float:
    """Embarrassingly parallel kernel: 35 FMA + trig iterations per element, no shared writes."""
    start, end = rng
    sin = math.sin
    total = 0.0
    for i in range(start, end):
        x = 1e-6 * (i + 1)
        for k in range(35):
            x = x * 0.9999 + 1e-4 * sin(x + k)
        total += x
    return total


def split(n, p):
    return [(t * n // p, (t + 1) * n // p) for t in range(p)]


def trial_factory(pool, n, p, stage_a_times):
    ranges = split(n, p)
    n_serial = int(SERIAL_FRAC * n)

    def trial():
        t0 = time.perf_counter_ns()
        stage_a(n_serial)
        t1 = time.perf_counter_ns()
        stage_a_times.append((t1 - t0) / 1e6)
        pool.map(stage_b, ranges, chunksize=1)
    return trial


def measure(p, n):
    sa = []
    with mp.Pool(processes=p) as pool:          # created outside the timed region
        pool.map(stage_b, split(p * 2, p))     # make sure every worker is alive
        st = run_benchmark(trial_factory(pool, n, p, sa), WARMUP, TIMED)
    return st, statistics.median(sa[WARMUP:])


def main():
    out = []
    P, PL = p_phys(), p_log()
    h = hw()

    log(out, f"=== Phase 2A: strong scaling, N = {N_STRONG} ===")
    strong = []
    for p in range(1, PL + 1):
        st, ta = measure(p, N_STRONG)
        T1 = strong[0]["T"] if strong else st.median_ms
        S = T1 / st.median_ms
        strong.append({"p": p, "T": st.median_ms, "iqr": st.iqr_ms, "T_A": ta, "S": S, "E": S / p})
        log(out, f"p={p:2d}  T={st.median_ms:10.2f} ms  (StageA {ta:8.2f} ms)  S={S:6.3f}  E={S/p:6.3f}")

    log(out, f"=== Phase 2B: weak scaling, N0 = {N0_WEAK} per worker ===")
    weak = []
    for p in range(1, PL + 1):
        st, ta = measure(p, p * N0_WEAK)
        T1 = weak[0]["T"] if weak else st.median_ms
        alpha = ta / st.median_ms
        SG = p - alpha * (p - 1)
        weak.append({"p": p, "N": p * N0_WEAK, "T": st.median_ms, "iqr": st.iqr_ms, "T_A": ta,
                     "E_weak": T1 / st.median_ms, "alpha": alpha, "S_G": SG})
        log(out, f"p={p:2d}  N={p*N0_WEAK:9d}  T={st.median_ms:10.2f} ms  E_weak={T1/st.median_ms:6.3f}  "
                 f"alpha={alpha:.4f}  S_G={SG:6.3f}")

    # Amdahl analysis
    s = strong[0]["T_A"] / strong[0]["T"]
    S_inf = 1 / s
    S_amdahl_PL = 1 / (s + (1 - s) / PL)
    S_obs_PL = strong[-1]["S"]
    log(out, f"serial fraction s = {s:.4f}  S_inf = {S_inf:.3f}  "
             f"Amdahl S({PL}) = {S_amdahl_PL:.3f}  observed S({PL}) = {S_obs_PL:.3f}")

    # Inflection: P-core -> E-core cluster on Apple Silicon, or P_phys -> SMT siblings
    if h.get("p_cores") and h.get("e_cores"):
        B, kind = int(h["p_cores"]), "P-core -> E-core cluster"
    elif PL > P:
        B, kind = P, "physical -> SMT/Hyper-Threading"
    else:
        B, kind = None, "none (P_log == P_phys, homogeneous)"
    dS = [None] + [strong[i]["S"] - strong[i - 1]["S"] for i in range(1, len(strong))]
    infl = {"boundary": B, "kind": kind}
    if B and B < PL:

        after = [d for i, d in enumerate(dS) if d is not None and strong[i]["p"] > B]
        mb, ma = statistics.mean(before), statistics.mean(after)
        infl.update({"mean_dS_before": mb, "mean_dS_after": ma,
                     "drop_pct": (1 - ma / mb) * 100 if mb else 0.0,
                     "dS_at_B": dS[B - 1] if B >= 2 else None, "dS_at_B1": dS[B]})
        log(out, f"Inflection at p={B}->{B+1} ({kind}): mean marginal dS/worker "
                 f"{mb:.3f} -> {ma:.3f}  (drop {infl['drop_pct']:.1f}%)")
    else:
        log(out, f"No architectural boundary inside 1..{PL}: {kind}")

    S_G_PL = weak[-1]["S_G"]
    tag = emit_verify_tag("PHASE2", STUDENT_ID, S_obs_PL, S_G_PL)
    log(out, f"S_strong(P_log)={S_obs_PL:.4f}  S_Gustafson(P_log)={S_G_PL:.4f}")
    log(out, tag)
    save_results("phase2", {"N_strong": N_STRONG, "N0": N0_WEAK, "strong": strong, "weak": weak,
                            "dS": dS, "s": s, "S_inf": S_inf, "S_amdahl_PL": S_amdahl_PL,
                            "S_obs_PL": S_obs_PL, "S_G_PL": S_G_PL, "inflection": infl,
                            "verify": tag, "log": out})


if __name__ == "__main__":
    main()
```

```python
"""Phase 3A - empirical machine roofline: DRAM bandwidth + Python FMA ceiling."""
import multiprocessing as mp
from multiprocessing import shared_memory

from harness import run_benchmark, emit_verify_tag
from lab_common import STUDENT_ID, save_results, scale, p_phys, attach_shm, log

BUF_BYTES = scale(96 * 10**6, 8 * 10**6)
FLOPS_PER_WORKER = scale(80_000_000, 4_000_000)
WARMUP, TIMED = scale(2, 1), scale(7, 3)

_g = {}


def init_bw(name_a, name_b):
    _g["a"] = attach_shm(name_a)
    _g["b"] = attach_shm(name_b)
    _g["mva"] = _g["a"].buf
    _g["mvb"] = _g["b"].buf


def copy_slice(rng):
    s, e = rng
    _g["mva"][s:e] = _g["mvb"][s:e]          # native memcpy: 1 read + 1 write per byte
    return e - s


def fma_worker(iters):
    a, b = 0.999999, 1e-6
    x0 = x1 = x2 = x3 = x4 = x5 = x6 = x7 = 0.1
    x8 = x9 = x10 = x11 = x12 = x13 = x14 = x15 = 0.2
    for _ in range(iters):                    # 16 FMAs x 2 FLOPs = 32 FLOPs / iteration
        x0 = x0 * a + b; x1 = x1 * a + b; x2 = x2 * a + b; x3 = x3 * a + b
        x4 = x4 * a + b; x5 = x5 * a + b; x6 = x6 * a + b; x7 = x7 * a + b
        x8 = x8 * a + b; x9 = x9 * a + b; x10 = x10 * a + b; x11 = x11 * a + b
        x12 = x12 * a + b; x13 = x13 * a + b; x14 = x14 * a + b; x15 = x15 * a + b
    return x0 + x1 + x2 + x3 + x4 + x5 + x6 + x7 + x8 + x9 + x10 + x11 + x12 + x13 + x14 + x15


def main():
    out = []
    P = p_phys()
    A = shared_memory.SharedMemory(create=True, size=BUF_BYTES)
    B = shared_memory.SharedMemory(create=True, size=BUF_BYTES)
    try:
        B.buf[:BUF_BYTES] = bytes(range(256)) * (BUF_BYTES // 256) + bytes(BUF_BYTES % 256)
        ranges = [(t * BUF_BYTES // P, (t + 1) * BUF_BYTES // P) for t in range(P)]
        with mp.Pool(P, initializer=init_bw, initargs=(A.name, B.name)) as pool:
            pool.map(copy_slice, ranges)      # touch pages once
            st = run_benchmark(lambda: pool.map(copy_slice, ranges, chunksize=1), WARMUP, TIMED)
        assert bytes(A.buf[:4096]) == bytes(B.buf[:4096])
    finally:
        for s in (A, B):
            s.close()
            s.unlink()
    bw = 2 * BUF_BYTES / ((st.median_ms / 1e3) * 1e9)
    log(out, f"=== Phase 3A: roofline (P_phys = {P}) ===")
    log(out, f"Copy {BUF_BYTES/1e6:.0f} MB (x2 buffers): median {st.median_ms:.3f} ms, "
             f"IQR {st.iqr_ms:.3f} ms  => BW_sustained = {bw:.3f} GB/s")

    iters = FLOPS_PER_WORKER // 32
    with mp.Pool(P) as pool:
        pool.map(fma_worker, [1000] * P)
        st2 = run_benchmark(lambda: pool.map(fma_worker, [iters] * P, chunksize=1), scale(1, 0), scale(5, 3))
    gflops = P * iters * 32 / ((st2.median_ms / 1e3) * 1e9)
    log(out, f"FMA loop {P} x {iters*32:.3g} FLOPs: median {st2.median_ms:.2f} ms  "
             f"=> P_sustained = {gflops:.4f} GFLOP/s")
    ridge = gflops / bw
    log(out, f"Ridge point I* = P/BW = {ridge:.6f} FLOP/Byte")
    save_results("phase3a", {"P": P, "buf_bytes": BUF_BYTES, "bw_ms": st.median_ms, "bw_iqr": st.iqr_ms,
                             "BW": bw, "fma_ms": st2.median_ms, "P_sust": gflops, "ridge": ridge, "log": out})


if __name__ == "__main__":
    main()
```

```python
BS_LIST = [4, 8, 12, 16, 24, 32, 48, 64, 96, 128]
WARMUP, TIMED = scale(1, 0), scale(3, 1)

_g = {}


def init_gemm(na, nb, nc, n):
    for k, nm in (("A", na), ("B", nb), ("C", nc)):
        shm = attach_shm(nm)
        _g["shm" + k] = shm
        _g[k] = shm.buf.cast("d")
    _g["N"] = n


def v1_naive(r0, r1):
    A, B, C, n = _g["A"], _g["B"], _g["C"], _g["N"]
    for i in range(r0, r1):
        io = i * n
        for j in range(n):
            dot = 0.0
            for k in range(n):
                dot += A[io + k] * B[k * n + j]       # B walked with stride N
            C[io + j] = dot


def v2_ikj(r0, r1):
    A, B, C, n = _g["A"], _g["B"], _g["C"], _g["N"]
    for i in range(r0, r1):
        io = i * n
        crow = [0.0] * n
        for k in range(n):
            aik = A[io + k]                           # hoisted
            brow = B[k * n:(k + 1) * n]               # contiguous row slice (zero-copy view)
            for j in range(n):
                crow[j] += aik * brow[j]              # unit stride
        C[io:io + n] = array("d", crow)


def v3_blocked(r0, r1, bs):
    A, B, C, n = _g["A"], _g["B"], _g["C"], _g["N"]
    cloc = [[0.0] * n for _ in range(r1 - r0)]
    for ii in range(r0, r1, bs):
        imax = min(ii + bs, r1)
        for jj in range(0, n, bs):
            jmax = min(jj + bs, n)
            for kk in range(0, n, bs):
                kmax = min(kk + bs, n)
                for i in range(ii, imax):              # micro-kernel order i-k-j
                    crow = cloc[i - r0]
                    io = i * n
                    for k in range(kk, kmax):
                        aik = A[io + k]                # hoisted out of j-loop
                        brow = B[k * n + jj:k * n + jmax]   # hoisted tile slice
                        j = jj
                        for b in brow:
                            crow[j] += aik * b
                            j += 1
    for i in range(r0, r1):
        C[i * n:(i + 1) * n] = array("d", cloc[i - r0])


def task(args):
    variant, r0, r1, bs = args
    if variant == 1:
        v1_naive(r0, r1)
    elif variant == 2:
        v2_ikj(r0, r1)
    else:
        v3_blocked(r0, r1, bs)
    return r1 - r0
```

```python
"""Phase 4 - skewed workload: static block vs cyclic vs dynamic chunk queue."""
import math
import multiprocessing as mp
import time

from harness import run_benchmark, emit_verify_tag
from lab_common import STUDENT_ID, save_results, scale, p_phys, log

N = scale(12_000, 3_000)
CHUNKS = [1, 4, 16, 64, 256, 1024]
WARMUP, TIMED = scale(0, 0), scale(3, 1)


def item(i: int) -> float:
    k = 1 + int((i / 60) ** 2)            # K(i) = 1 + floor((i/60)^2)
    x = 0.5 + (i % 7) * 0.01
    sin, cos, sqrt = math.sin, math.cos, math.sqrt
    for _ in range(k):
        x = sqrt(abs(sin(x) + cos(x)) + 0.5)
    return x


def w_block(t, p, n, times):
    t0 = time.perf_counter_ns()
    for i in range(t * n // p, (t + 1) * n // p):
        item(i)
    times[t] = (time.perf_counter_ns() - t0) / 1e6


def w_cyclic(t, p, n, times):
    t0 = time.perf_counter_ns()
    for i in range(t, n, p):
        item(i)
    times[t] = (time.perf_counter_ns() - t0) / 1e6


def w_dynamic(t, p, n, times, counter, chunk):
    t0 = time.perf_counter_ns()
    while True:
        with counter.get_lock():          # synchronised claim on the shared index
            start = counter.value
            counter.value = start + chunk
        if start >= n:
            break
        for i in range(start, min(start + chunk, n)):
            item(i)
    times[t] = (time.perf_counter_ns() - t0) / 1e6


def run_strategy(p, kind, chunk=0):
    records = []

    def once():
        times = mp.Array("d", p)
        if kind == "dynamic":
            counter = mp.Value("i", 0)
            procs = [mp.Process(target=w_dynamic, args=(t, p, N, times, counter, chunk)) for t in range(p)]
        else:
            fn = w_block if kind == "block" else w_cyclic
            procs = [mp.Process(target=fn, args=(t, p, N, times)) for t in range(p)]
        t0 = time.perf_counter_ns()
        for pr in procs:
            pr.start()
        for pr in procs:
            pr.join()
        wall = (time.perf_counter_ns() - t0) / 1e6
        records.append((wall, list(times)))

    st = run_benchmark(once, WARMUP, TIMED)
    timed = records[WARMUP:]
    wall, tw = min(timed, key=lambda r: abs(r[0] - st.median_ms))   # run nearest the median
    lam = max(tw) / (sum(tw) / p)
    return {"T_wall": st.median_ms, "iqr": st.iqr_ms, "t_worker": tw, "lambda": lam}


def main():
    out = []
    P = p_phys()
    work = [1 + int((i / 60) ** 2) for i in range(N)]
    log(out, f"=== Phase 4: skewed workload N = {N}, p = P_phys = {P} ===")
    log(out, f"K(0) = {work[0]}, K(N-1) = {work[-1]}, total iterations = {sum(work)}")

    rows = []
    for label, kind, c in ([("Static block", "block", 0), ("Static cyclic", "cyclic", 0)] +
                           [(f"Dynamic C={c}", "dynamic", c) for c in CHUNKS]):
        r = run_strategy(P, kind, c)
        r.update({"label": label, "kind": kind, "chunk": c})
        rows.append(r)
        log(out, f"{label:16s} T_wall={r['T_wall']:10.2f} ms  IQR={r['iqr']:7.2f}  lambda={r['lambda']:.3f}  "
                 f"t_worker=[{', '.join(f'{x:.0f}' for x in r['t_worker'])}]")

    dyn = [r for r in rows if r["kind"] == "dynamic"]
    best = min(dyn, key=lambda r: r["T_wall"])
    c_star = best["chunk"]
    T1 = rows[0]["T_wall"]
    log(out, f"C* = {c_star}  speedup over static block = {T1 / best['T_wall']:.2f}x")
    tag = emit_verify_tag("PHASE4", STUDENT_ID, T1, best["T_wall"])
    log(out, f"T_wall(Strategy 1)={T1:.4f}  T_wall(Strategy 3, C*)={best['T_wall']:.4f}")
    log(out, tag)
    save_results("phase4", {"N": N, "P": P, "rows": rows, "c_star": c_star, "verify": tag, "log": out})


if __name__ == "__main__":
    main()
```

    w(f"\n**GEMM N = {p3b['N']}, {p3b['P']} worker processes**\n")
    rows = []
    for r in p3b["results"]:
        rows.append([r["name"], r["bs"] or "—", f(r["ms"], 1), f(r["gflops"], 5),
                     kb(r["W_tile"]) if r.get("W_tile") else "—", r.get("fits", "—"),
                     ("OK " + f"{r['max_err']:.1e}") if r.get("ok") else ("FAIL" if "ok" in r else "—")])
    w(md_table(["Variant", "BS", "median (ms)", "GFLOP/s", "W_tile = 3·BS²·8", "fits in", "max|C3−C2|"], rows))
    bs = p3b["bs_star"]
    W = 3 * bs * bs * 8
    v2g = p3b["results"][1]["gflops"]
    best_g = max(r["gflops"] for r in p3b["results"] if r["bs"])
    total = 3 * p3b["N"] ** 2 * 8
    v3 = [r for r in p3b["results"] if r["bs"]]
    mono = all(v3[i]["gflops"] <= v3[i + 1]["gflops"] * 1.01 for i in range(len(v3) - 1))
    w(f"\n**Cache-capacity analysis.** The best tile is **BS* = {bs}**, footprint W_tile = {W:,} B "
      f"({kb(W)}), against L1d = {kb(h['l1d_bytes'])} and L2 = {kb(h['l2_bytes'])}. "
      + ("Throughput rises almost steadily with BS, so the optimum is the largest tile tested. "
         if mono else "") +
      "Small tiles lose because the six-level loop nest re-enters Python loops and creates new slices very "
      "often, so loop overhead dominates. ")
    if h.get("l2_bytes") and total <= h["l2_bytes"]:
        w(f"The key point is that the whole problem (3 × {p3b['N']}² × 8 B = {total/2**20:.2f} MB) already fits "
          f"in this CPU's {kb(h['l2_bytes'])} L2, so there are no DRAM misses for tiling to remove. Tiling only "
          "adds loop overhead, which is why Variant 3 "
          + (f"never beats Variant 2 ({best_g:.4f} vs {v2g:.4f} GFLOP/s) and " if best_g < v2g else "")
          + "approaches Variant 2 as BS grows. The audit expectation that W_tile(BS*) fits L1d does not hold "
            "for CPython: the bottleneck is bytecode dispatch, not cache capacity.\n")
    else:
        w("Large tiles stop fitting the inner cache levels and approach Variant 2's behaviour. In CPython the "
          "interpreter overhead dominates, so the optimum is set by loop overhead as much as by cache size.\n")
    w("**Roofline mapping** (attainable = min(P_sustained, I × BW))\n")
    w(md_table(["Kernel", "I (FLOP/B)", "Attainable (GFLOP/s)", "Achieved (GFLOP/s)", "% of attainable", "region"],
               [[m["name"], f(m["I"], 4), f(m["attainable"], 4), f(m["gflops"], 5), f(m["pct"], 1), m["bound"]]
                for m in p3b["mapping"]]))
    w(f"\nI_naive ≈ 0.125 FLOP/B and I_tiled(BS*) = BS*/12 = {bs/12:.3f} FLOP/B. "
      f"Because the interpreter-bound compute ceiling is so low, the ridge point I* = {p3a['ridge']:.6f} "
      "lies far to the left of every kernel, so in pure Python all three variants sit in the compute "
      "(interpreter-dispatch) bound region. The speedups from Variant 1 → 2 → 3 therefore come mainly from "
      "removing index arithmetic and strided memoryview accesses from the hot loop, with cache locality as a "
      "secondary effect. Variant 2 is mapped at the naive intensity as a conservative estimate.\n")

    # ------------------------------------------------------------------ 5
    w("## 5. Phase 4 — Scheduling & Load Imbalance\n")
    w(f"N = {p4['N']:,} items, K(i) = 1 + ⌊(i/60)²⌋, p = {p4['P']}.\n")
    w(md_table(["Strategy", "T_wall (ms)", "IQR (ms)", "max t_worker (ms)", "mean t_worker (ms)", "λ"],
               [[r["label"], f(r["T_wall"], 1), f(r["iqr"], 1), f(max(r["t_worker"]), 1),
                 f(sum(r["t_worker"]) / len(r["t_worker"]), 1), f(r["lambda"], 3)] for r in p4["rows"]]))
    rr = {r["label"]: r for r in p4["rows"]}
    c1, c1024 = rr["Dynamic C=1"], rr["Dynamic C=1024"]
    cs = p4["c_star"]
    w(f"\n**Trade-off.** Static block gives λ = {rr['Static block']['lambda']:.2f}: the last worker owns the "
      "heaviest part of the triangle while the others idle at the join. Cyclic interleaving spreads heavy and "
      f"light items evenly (λ = {rr['Static cyclic']['lambda']:.2f}). In the dynamic queue, C = 1 balances "
      f"almost perfectly (λ = {c1['lambda']:.3f}) but every item costs a lock acquire on the shared counter, "
      "whose cache line bounces between cores (T_wall = %.1f ms). C = 1024 claims only ~%d chunks in total, so "
      "synchronisation is negligible, but the last chunks are huge and the tail is unbalanced "
      "(λ = %.3f, T_wall = %.1f ms). The best chunk on this CPU is **C* = %d** (T_wall = %.1f ms, λ = %.3f), "
      "%.2f× faster than static block.\n" % (c1["T_wall"], -(-p4["N"] // 1024), c1024["lambda"], c1024["T_wall"],
                                             cs, rr[f"Dynamic C={cs}"]["T_wall"], rr[f"Dynamic C={cs}"]["lambda"],
                                             rr["Static block"]["T_wall"] / rr[f"Dynamic C={cs}"]["T_wall"]))
    dyn = sorted((r for r in p4["rows"] if r["kind"] == "dynamic"), key=lambda r: r["T_wall"])
    if len(dyn) > 1 and (dyn[1]["T_wall"] - dyn[0]["T_wall"]) < max(dyn[0]["iqr"], dyn[1]["iqr"]):
        w(f"C = {dyn[0]['chunk']} and C = {dyn[1]['chunk']} differ by only "
          f"{dyn[1]['T_wall'] - dyn[0]['T_wall']:.1f} ms, inside the measurement noise, so any chunk in that "
          "range is effectively optimal: each item here costs milliseconds of work, so even one lock per item "
          "is cheap compared with the work it protects. ")
    cyc = rr["Static cyclic"]
    if cyc["T_wall"] < dyn[0]["T_wall"]:
        w(f"Cyclic static scheduling was slightly faster than the best dynamic run ({cyc['T_wall']:.1f} vs "
          f"{dyn[0]['T_wall']:.1f} ms): the skew K(i) changes smoothly, so round-robin already balances the work "
          f"(λ = {cyc['lambda']:.3f}) with zero synchronisation. Dynamic scheduling would win for irregular "
          "skew that cyclic distribution cannot predict, and on a hybrid CPU it also lets fast cores take more "
          "items than slow ones.\n")
    else:
        w("\n")

    # ------------------------------------------------------------------ logs + code
    w("## Appendix A — Raw terminal telemetry\n")
    for name, ph in (("Phase 0", p0), ("Phase 1", p1), ("Phase 2", p2), ("Phase 3A", p3a),
                     ("Phase 3B", p3b), ("Phase 4", p4)):
